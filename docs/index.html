🍩 Donut Balance Tracker

Type /moneycheck to see how much your DonutSMP balance is up or down since midnight.

Download latest .jar

Setup

  1. Install Fabric Loader and the matching Fabric API for the Minecraft version this mod targets.
  2. Drop the downloaded jar into your .minecraft/mods folder.
  3. Launch the game once so it generates config/donutbalance.json.
  4. In-game on DonutSMP, run /api to get your personal API key.
  5. Close the game, open config/donutbalance.json, and paste your key in: 
    {
  "apiKey": "your-key-here",
  "refreshIntervalSeconds": 60
}
  6. Relaunch, join DonutSMP, and type /moneycheck in chat.

Your API key is personal and lets DonutSMP's API act as you. Never share it or commit it to a public repo — the config file is git-ignored for exactly that reason.

How "since midnight" works

DonutSMP's API only reports your current balance — it has no history endpoint. So the mod remembers the first balance it sees each day (your computer's local midnight) as the day's baseline, and compares every later reading against it. That baseline is saved to disk so restarting the game doesn't reset it until the next real midnight.
